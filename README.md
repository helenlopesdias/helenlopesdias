## 🔍 Análise da Efetividade do MED e do Bloqueio Cautelar no Pix

### 📖 Contexto

Projeto desenvolvido utilizando dados públicos do Banco Central do Brasil para avaliar a eficiência dos mecanismos de recuperação de valores em casos de fraude via Pix.

A análise busca responder questões importantes como:

- Quanto do valor fraudado é efetivamente recuperado?
- O MED está funcionando?
- O Bloqueio Cautelar é eficiente?
- Quais fatores impedem a recuperação dos recursos?
- O crescimento das fraudes acompanha a expansão do Pix?

### 🛠️ Tecnologias

- SQL
- Google BigQuery
- Power BI
- DAX
- Modelagem de Dados

### 🎯 Principais Entregas

✅ Tratamento e consolidação de múltiplas bases públicas

✅ Construção de indicadores financeiros

✅ Desenvolvimento de métricas de recuperação

✅ Dashboard analítico com foco executivo

✅ Storytelling de dados voltado à tomada de decisão
